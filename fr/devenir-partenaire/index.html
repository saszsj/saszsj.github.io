Vous connaissez une entreprise qui cherche à créer un site sur mesure, à intégrer l’IA ou à automatiser une tâche ? Présentez-lui ZSJ et suivez les demandes de contact issues de vos recommandations.

Comment recommander ZSJ

  1. Demandez votre accès

    Indiquez votre nom et votre e-mail dans le formulaire. Une fois votre candidature approuvée par ZSJ, vous recevrez par e-mail votre lien public et le code privé de votre espace apporteur.

  2. Partagez votre lien

    Envoyez uniquement le lien public aux entreprises que vous souhaitez présenter. Gardez le code privé pour consulter votre tableau de bord.

  3. Laissez l’entreprise présenter son besoin

    Dans le chat, l’entreprise décrit son projet. L’assistant lui propose une solution avec une fourchette de prix. Si elle est intéressée, elle peut laisser son e-mail pour être recontactée par un consultant ZSJ.

Ce que vous voyez dans votre espace

Visiteurs recommandés
Avec l’accord du visiteur, ZSJ compte son navigateur une fois et retient le premier lien partenaire reconnu pendant 30 jours. L’attribution vaut pour ce navigateur.
Demandes de contact
Si un visiteur recommandé laisse son e-mail pour être recontacté, sa demande est comptée une fois par adresse dans votre espace. Vous voyez les totaux. Les adresses restent confidentielles.

Votre candidature

Les deux champs sont obligatoires. Le responsable de ZSJ examinera votre demande. Si elle est approuvée, vous recevrez vos accès à l’adresse indiquée.
